12.Marquee跑马灯 ​

名称说明其他
data-jds25="jdsMarquee"🐟
data-jds25="jdsMarqueeWrap"html 结构必须如此
html
<div data-jds25="jdsMarquee">
    <ul data-jds25="jdsMarqueeWrap">
        <li><img src="./img/dummy-400x400.png" alt="1"></li>
        <li><img src="./img/dummy-363x363.svg" alt="2"></li>
        <li><img src="./img/dummy-400x400.png" alt="3"></li>
        <li><img src="./img/dummy-363x363.svg" alt="4"></li>
        <li><img src="./img/dummy-400x400.png" alt="5"></li>
        <li><img src="./img/dummy-363x363.svg" alt="6"></li>
    </ul>
</div>
scss
&[data-jds25=jdsMarquee]{
    margin: 0 auto;
    border: 1px solid #ccc;
    [data-jds25=jdsMarqueeWrap]{
        margin: 0;
        padding: 0;
        li{
            margin: 0;
            padding: 10px 5px;
            width: 300px;
            img{
                display: block;
                width: 100%;
            }
        }
    }
}
